CADForge: watch the part get built

Hero animation for the CADForge write-up. A flanged bearing housing (Ø100 flange, six M8 holes on a 75 mm bolt circle) built feature by feature in real CadQuery. Every frame shows a true intermediate solid from the OpenCASCADE kernel. Rendered in Blender 5 EEVEE at 1440×1080 (4:3, the hero's crop), 30 fps, 18.4 s loop. Captions are HTML, timed from video.currentTime. Click a video to pause it.

A · Chips

Reference-style caption chip: red eyebrow, words fading in. Exact B-rep edges drawn as thin dark lines.

B · Chips + code applied to the page

Same video. The chip also types the CadQuery line behind each feature, a history bar tracks the rewind and replay, and an "agent" tag follows the action.

C · No edge lines

Shading only, no edge lines, closer to the reference's viewer. Same chips as A.
