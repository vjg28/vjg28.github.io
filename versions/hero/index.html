Hero variants

Each page is the real homepage with only the hero swapped. All four share the optical name alignment and icon-only links; they differ in scale and how the role line and icons are grouped.

  1. ATuned original

    Same order as before: tighter type scale, name pulled onto the text edge, quiet icon row with labels on hover.

  2. BHairline applied to the site

    Larger name, and a short amber rule that separates the motto from the role line and icons, which sit together as one block.

  3. CKicker

    The role line moves above the name as a small editorial kicker; on phones it drops back below the motto so it doesn't run into the portrait.

  4. DByline row

    The largest name. Role line and icons share one row split by a vertical hairline. Compact, but it brings back the long line.
