Kaggle Wins

A gold in American Express Default Prediction and a silver in Feedback Prize, both as part of small teams.

Aug – Sep 20226 min read

In the summer of 2022 I spent my evenings on two very different Kaggle competitions: one about predicting credit default from tabular time series, the other about judging the quality of argumentative essays. Both ended with medals, and both were team efforts. Here's what each solution did.

American Express: diversity over a single best model

The task was to predict whether a customer would default, from monthly statement profiles. Our 16th-place solution leaned on two ideas: varied feature sets, and a diverse ensemble.

Feature engineering

Mean, standard deviation and last-value features were common to every model. On top of that we trained in three ways:

  • only Hull moving average (HMA) features,
  • only difference features,
  • HMA and difference features together, which only worked with CatBoost.

Using every difference feature turned out to be the wrong call for some models: for neural networks and XGBoost they introduced leakage, and cross-validation stopped correlating with the leaderboard. HMA features proved much better than differences.

Ensemble

Cross-validation and the leaderboard tracked each other well, so we used Optuna to pick ensemble weights and submitted a rank ensemble. A few strong public models had no out-of-fold predictions, so their weights were set by hand.

In hindsight, our best submission (0.80839) wasn't one we picked, and giving more weight to TabNet and LightGBM would have landed us 13th. Things we didn't get to try: predicting the missing values of B_29 and using them as features, LightGBM on HMA features, and pseudo-labelling on the private test data.

Feedback Prize: one model, one clever embedding

Here the task was to rate each argumentative element in a student essay (claim, evidence, rebuttal and so on) as ineffective, adequate or effective. Our 14th-place result came from a single strong model, run with a few variations and averaged.

Domain pre-training

First, DeBERTa-v3-large was further pre-trained as a masked language model on all the essays from the previous Feedback competition, reaching a perplexity of about 4.5.

Framing it as token classification

Inspired by a public kernel from Nicholas Broad, each essay became one sequence, with special tokens marking where each discourse element starts and ends:

[CLS] some text [CLS_CLAIM] the claim text [END_CLAIM] ... [SEP]

Every token gets a discourse-type id. Only the start and end tokens of each element carry an effectiveness label; everything else is ignored in the loss.

The lift: a discourse-type embedding

The change that helped most was adding a second embedding table for discourse types inside DeBERTa's embedding layer and summing it with the word embeddings, so every token knows what kind of argument it belongs to:

self.disc_type_embeddings = nn.Embedding(9, self.embedding_size)
...
embeddings += self.disc_type_embeddings(disc_type_ids)

Training used AdamW with a polynomial learning-rate schedule over five folds. At inference, the probabilities at each element's start and end tokens were averaged to get its label.

The write-up and full code were published by Abhishek Thakur, using his training library tez. Original write-up ↗
