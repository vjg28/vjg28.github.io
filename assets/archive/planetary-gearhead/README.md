# Planetary gearhead renders (archived)

These were the CADForge write-up images from Nov 2026, kept for later use. They show a "CF-104" planetary gearhead modelled in CadQuery and rendered in Blender 5.0.1 (Cycles, Metal, AgX).

- gearhead-pair.jpg: two units, one with its cover off and one closed (1600×1200)
- gearhead-macro.jpg: close-up of the output hub (1920×1080)
- gearhead-explode.jpg: exploded assembly (1920×1080)
- source/model.py: the CadQuery model, which exports the part STLs
- source/scene.py, post.py, final.sh: the Blender scene, the post-processing and the final render run
